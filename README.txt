여신 용어사전 - 웹 배포 안내 (아이폰·안드로이드 공용)

[1] 올리기
- 이 폴더의 파일 전체를 웹 호스팅(예: GitHub Pages, Netlify, Cloudflare Pages 등)의 최상위 위치에 올립니다.
- index.html이 맨 위(루트)에 있어야 합니다. 폴더 안의 폴더로 올리지 마세요.
- 올린 뒤 https:// 로 시작하는 주소가 생기면 성공입니다. (https가 아니면 홈 화면 설치와 오프라인 기능이 동작하지 않습니다.)

[2] 카카오톡으로 보내기
- 위 주소(링크)를 카카오톡으로 보냅니다.

[3] 받은 사람이 쓰는 방법
아이폰: 링크 → 카카오톡 안에서 열리면 "Safari로 열기" 선택 → 공유 버튼 → "홈 화면에 추가"
안드로이드: 링크 → Chrome으로 열기 → 메뉴(⋮) → "홈 화면에 추가" 또는 "앱 설치"
- 한 번 열어 두면 이후에는 인터넷이 없어도 열립니다. (홈 화면에 추가해 둔 경우)

[4] 개인정보
- 앱은 이름, 전화번호, 계정 같은 개인정보를 묻지 않고 수집하지 않습니다.
- 검색어와 즐겨찾기는 받은 사람의 폰(브라우저)에만 저장되며, 어디로도 전송되지 않습니다.
- 앱 안에는 통계·광고·추적 코드가 없습니다.
- 다만 웹 호스팅 업체는 접속 기록(IP 주소 등)을 서버에 남길 수 있습니다. 이는 앱이 아니라 호스팅 서비스의 방침입니다.

[5] 한계
- 링크를 아는 사람은 누구나 열 수 있습니다. "받은 폰에서만 동작"하게 강제하려면 접속 코드를 서버에서 확인하는 방식 등이 별도로 필요합니다.
- 용어 내용은 하나은행 내부 교재를 바탕으로 정리한 것입니다. 배포 전에 내부 자료 배포 규정을 확인하세요.

[6] 용어를 고쳐서 다시 올릴 때
- terms.js 또는 calcs.js를 수정하고, sw.js 맨 위의 VERSION 숫자(v3 → v4 …)를 올린 뒤 다시 올립니다. 그래야 이미 설치한 폰에도 새 내용이 반영됩니다.
